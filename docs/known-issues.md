# WxRust 已知问题与已接受风险（Known Issues）

> 本文件记录当前已识别、但**有意接受或依赖外部条件解决**的风险与限制。
> 每一项都标注严重度、缓解措施与解除条件。对应 issue：#1 / #3。

## 1. RSA Marvin Attack（RUSTSEC-2023-0071）—— 已缓解，待上游修复

- **严重度**：medium（cargo audit / cargo deny 报告）
- **状态**：`deny.toml` 显式例外（`ignore = ["RUSTSEC-2023-0071"]`），接受为已知风险
- **根因**：rsa 0.9.10 是 0.9.x 唯一稳定版，Marvin 时序侧信道修复需等 rsa 0.10 stable
- **缓解措施**（有测试证据，见 `wx_pay_v3_crypto_test.rs::rsa_oaep_roundtrip_marvin_mitigation_evidence`）：
  1. 私钥解密路径统一走 **RSA-OAEP**（内建完整性校验，暴露面小于 PKCS#1 v1.5 裸解密）
  2. 全库不存在对任意密文执行 PKCS#1 v1.5 解密的使用点（v1.5 仅用于确定性 RSA-SHA256 签名，不受 Marvin 影响）
- **解除条件**：rsa 0.10 stable 发布后升级、移除 deny.toml 例外（Phase D 跟踪项）

## 3. pay 模块真实商户端到端未验证

- **严重度**：P1（影响"全场景验证"结论）
- **状态**：v2/v3 加解密、签名、验签、通知解析均有 Mock + golden 测试；但**真实商户下单/支付回调/退款/对账单下载**需要真实商户号 + apiclient_key/cert（p12）
- **解除条件**：接入方提供测试商户凭证后执行 `send_real_message` 同款真实流量脚本

## 4. 微信真实环境依赖凭证（Alpha 已验证部分）

- **状态**：订阅消息 + 客服消息 + access_token + 验签 + 错误映射 + token 过期重试已**真实验证通过**（2026-08-27，双通道送达 errcode=0 + 人工确认）
- **限制**：
  - 一次性订阅消息：每次送达消耗一次用户授权（需用户重新授权后再测）
  - 客服消息：48h 窗口（用户先发消息）内可主动推送
- **解除条件**：无（已闭环）；后续功能（支付回调等）依赖第 3 项凭证
