## 三、Rust 义务完成度

23 项义务测试（见对照表 R01–R23）全部通过，关键项：

- **并发**：token 双检锁 single-flight（N 并发仅 1 次刷新）、并发写不丢更新、重复检查器并发安全、TTL 边界
- **所有权/引用**：session 共享引用同一性（`ptr::eq`）、失效重建
- **错误**：`WxErrorException` 变体、`Display` 合同、畸形 JSON/超大码值不 panic
- **serde**：未知字段容忍、缺失字段默认、wire format 精确
- **安全**：XXE 拒绝、PKCS7 非法填充拒绝、空密文/坏 key 拒绝、宽松 base64 掩码
- **编码**：Latin-1→UTF-8 文件名、RFC 3986 URI 编码
- **类型系统**：`Send + Sync` 编译期断言、redis feature 门控

## 五、覆盖率与可比 scope

| 指标 | 值 | 说明 |
|---|---|---|
| line | **26.07%**（1084/4158） | — |
| function | **50.28%**（89/177） | 实现函数约半数被触达 |
| region | **19.46%**（740/3802） | 分支面低覆盖集中在数据表与集成形态文件 |

**覆盖率不是等价证明**——26.07% 被三类结构性文件拉低：

1. **生成错误码表（2529 行，约 61% 生产行）**：`wx_open_error_msg_enum.rs` 1836 行、`wx_cp` 285、`wx_ma` 212、`wx_mp` 165、`wx_channel` 31——纯数据表，仅 `find()` 路径被测试（`wx_ma` 12.74% 来自 21 码 oracle；其余 0%）。数据由 `scripts/gen_error_msg_enums.py` 从 Java 枚举生成，正确性由生成器 + 抽样 oracle 保证，逐行覆盖无增益。
2. **`PLATFORM_NA` 对象文件（约 350 行）**：redis ops trait（57）、redis 分布式锁（91，集成形态）、媒体上传/下载执行器（56，需 HTTP mock 宿主）、`file_utils` 未测分支、bean_utils/sign_utils/random_utils/input_stream_data 等——按台账为平台 NA 或 V5 范畴。
3. **核心已测文件高覆盖**：`wx_error` 93.55%、`sha1` 97.56%、`wx_crypt_util` 88.09%、`data_utils` 90.70%、`http_response_proxy` 85.25%、`standard_session` 80.90%、`standard_session_manager` 75.00%、`xml_utils` 67.12%——**全部高风险语义核心均在 65% 以上**。

**同口径可比性**：Java 侧测试未执行（JDK 21 + Lombok 1.18.30 构建失败 `TypeTag :: UNKNOWN`，需 JDK 8），无 JVM 覆盖率数字，**禁止跨语言百分比对比**。本报告覆盖率为 Rust 侧内部信号。
