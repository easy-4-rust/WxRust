2. **门面默认实现低触达**：`api/wx_pay_service.rs`（666 行）31.38%——订单/退款/通知/其他业务域

   37.16%——多商户切换与 configMap 方法零测试触达（PR13）。
3. **已实现核心面覆盖集中且高**：v3 签名/证书/通知 utils 70%–90% line，测试以官方向量 +
